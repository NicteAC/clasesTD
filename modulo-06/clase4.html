Parte I — Fundamentos

¿Qué es un Evento DOM?

📌 Definición

Notificaciones que el navegador genera cuando el usuario interactúa con la página — clicks, teclas, movimientos del mouse, envíos de formularios.

⚙️ Funcionamiento

El DOM expone estos eventos a JavaScript. Cada evento tiene un tipo (click, input, submit) y puede asociarse a un elemento.

🖱️ Ratón

clickdblclickmouseovermouseleave

⌨️ Teclado

keydownkeyupkeypress

📋 Formulario

inputchangesubmit
Captura de Eventos

La directiva v-on y su alias @

Vue simplifica el manejo de eventos con una sintaxis declarativa:

<button v-on:click="incrementar">+</button> <button @click="incrementar">+</button> <button @click="saludar('hola')">Saludar</button> <input @input="log($event)" />

✅ Código más limpio

No manipulamos el DOM directamente con addEventListener

✅ Reactivo

Vue se encarga de suscribir y eliminar listeners automáticamente al montar/desmontar

✅ Separación clara

La lógica vive en methods, no en el HTML

Manejadores

Métodos manejadores de eventos

Funciones definidas en methods que se ejecutan al dispararse un evento.

// Template <button @click="incrementar">Sumar</button> <button @click="sumar(5)">+5</button> // Script export default { data() { return { contador: 0 } }, methods: { incrementar() { this.contador++ }, sumar(n) { this.contador += n } } }

Manejador en línea — para lógica breve:

<button @click="contador++">+</button> <input @input="valor = $event.target.value"/>

⚠️ Regla de oro

Si la lógica tiene más de 1–2 líneas, muévela a un método separado para mantener el HTML limpio.

Acceso al Evento

El objeto $event

Nos da acceso al evento nativo del DOM con todos sus detalles:

// Acceso al valor de un input <input @input="capturar($event)" /> capturar(e) { console.log(e.target.value) // texto console.log(e.target.name) // nombre input console.log(e.type) // 'input' } // Coordenadas del mouse <div @mousemove="mover($event)">...</div> mover(e) { this.x = e.clientX this.y = e.clientY }

📦 Propiedades clave del objeto evento

target currentTarget type key keyCode clientX / clientY preventDefault() stopPropagation()

💡 Pasar parámetros + $event

<button @click="accion(item, $event)"> Click </button>
Modificadores

Modificadores de eventos

Se agregan después del evento separados por punto — evitan código boilerplate en JS.

<form @submit.prevent="enviar">...</form> <button @click.stop="accion">...</button> <button @click.once="bienvenida">...</button> <div @click.self="cerrar">...</div> <a @click.stop.prevent="ir">Link</a>

.prevent

= preventDefault()

.stop

= stopPropagation()

.once

Se auto-elimina tras la 1ª ejecución

.self

Solo si el evento viene del elemento exacto

Modificadores de Tecla

Modificadores de teclado

<input @keydown.enter="buscar" /> <input @keydown.esc="limpiar" /> <div @keydown.up="moverArriba">...</div> <textarea @keydown.ctrl.enter="enviar"></textarea> <input @keydown.tab.prevent="siguiente"/>

Modificadores disponibles:

.enter .tab .esc .space .delete .up .down .left .right .ctrl .alt .shift .meta

✅ Ventaja

Sin estos modificadores, habría que verificar e.key === 'Enter' manualmente en JS. Vue lo hace por nosotros de forma declarativa.

💻 Demo 1 — Código

Template

<template> <div> <input v-model="nueva" @keydown.enter="agregar" placeholder="Nueva tarea..." /> <button @click="agregar">Agregar</button> <p v-if="error" class="error">{{ error }}</p> <ul> <li v-for="(t, i) in tareas" :key="i"> {{ t }} <button @click="eliminar(i)">✕</button> </li> </ul> <button @click.once="clickUnico">Solo una vez</button> </div> </template>

Script

export default { data() { return { nueva: '', tareas: [], error: '' } }, methods: { agregar() { const v = this.nueva.trim() if (!v) { this.error = 'Campo vacío'; return } if (this.tareas.includes(v)) { this.error = 'Ya existe'; return } this.tareas.push(v) this.nueva = '' this.error = '' }, eliminar(i) { this.tareas.splice(i, 1) }, clickUnico() { alert('Solo una vez!') } } }

Parte II — Avanzado

Eventos en la Composition API

En Vue 3 con <script setup> usamos defineEmits y emit() en lugar de this.$emit:

<script setup> import { ref } from 'vue' // Declaramos qué eventos puede emitir const emit = defineEmits(['actualizar', 'cerrar']) const valor = ref('') function confirmar() { emit('actualizar', valor.value) } </script> <template> <input v-model="valor" @keydown.enter="confirmar"/> <button @click="confirmar">OK</button> </template>

Options API (Vue 2 / Vue 3)

methods: { confirmar() { this.$emit('actualizar', dato) } }

🔑 Diferencias clave

  • No existe this en setup()
  • Los manejadores son funciones normales
  • Acceso reactivo con ref() y .value
Eventos Personalizados

Validación de eventos emitidos

Vue 3 permite validar el payload de eventos personalizados. Si devuelve false, emite una advertencia en consola.

export default { emits: { // Sin validación 'cerrar': null, // Con validación del payload 'enviar': (payload) => { return payload.email && payload.email.includes('@') && payload.mensaje.length >= 10 } }, methods: { submit() { this.$emit('enviar', { email: this.email, mensaje: this.mensaje }) } } }

👨‍👩‍👧 Comunicación padre ↔ hijo

<ContactoForm @enviar="procesarEnvio" /> procesarEnvio({ email, mensaje }) { // Recibe el payload validado this.confirmacion = `Enviado: ${email}` }

💡 Buena práctica

Declara siempre el array/objeto emits — mejora la documentación del componente y ayuda al editor a dar autocompletado.

Patrones de Diseño

Patrones de comunicación

🔭 Patrón Observador

Un componente (sujeto) emite eventos cuando su estado cambia. Otros (observadores) escuchan y reaccionan.

🎛 Patrón Mediador

Un store (Pinia/Vuex) o bus de eventos actúa como intermediario entre componentes no relacionados directamente.

Pinia Vuex mitt

Flujo de comunicación en Vue:

Props ↓ Datos del padre al hijo mediante propiedades
Events ↑ Notificaciones del hijo al padre mediante emit
Store ↔ Estado global para componentes no relacionados
Rendimiento

Debounce y Throttle

⏳ Debounce

Espera N ms desde el último evento antes de ejecutar. Ideal para búsquedas en tiempo real.

import { debounce } from 'lodash' const buscarDebounced = debounce((q) => { // Solo se llama 300ms después del último keyup api.buscar(q) }, 300)

⚡ Throttle

Ejecuta máximo 1 vez cada N ms aunque el evento se dispare más. Ideal para scroll o resize.

import { throttle } from 'lodash' const onScroll = throttle(() => { // Máximo 1 vez cada 200ms actualizarPosicion() }, 200)

✅ .once

Para eventos que deben ejecutarse exactamente una sola vez (ej: bienvenida, tutorial).

Accesibilidad

Eventos y accesibilidad

⌨️ Teclado

Toda funcionalidad disponible con mouse debe ser accesible con teclado (.enter, .space, .esc).

<button @click="accion" @keydown.enter="accion" @keydown.space.prevent="accion" >Botón accesible</button>

🏷 ARIA roles

Complementar eventos con atributos ARIA para lectores de pantalla.

<div role="button" aria-label="Eliminar tarea" tabindex="0" @click="eliminar" >✕</div>

👁 Feedback visual

Indicaciones claras de estado: focus visible, estados de carga, mensajes de confirmación o error.

<button :aria-busy="enviando" :aria-disabled="enviando" > {{ enviando ? 'Enviando...' : 'Enviar' }} </button>

💻 Demo 2 — ContactoForm.vue (hijo)

Template

<template> <form @submit.prevent="enviar"> <input v-model="email" type="email" placeholder="Email" aria-label="Correo electrónico" /> <textarea v-model="mensaje" placeholder="Mensaje (mín. 10 chars)" @keydown.ctrl.enter="enviar"></textarea> <p v-if="errorMsg" role="alert">{{ errorMsg }}</p> <button type="submit" :disabled="enviando" :aria-busy="enviando"> {{ enviando ? 'Enviando...' : 'Enviar' }} </button> </form> </template>

Script (Composition API)

<script setup> import { ref } from 'vue' const emit = defineEmits({ 'enviar': ({ email, mensaje }) => { return email.includes('@') && mensaje.length >= 10 } }) const email = ref('') const mensaje = ref('') const errorMsg = ref('') const enviando = ref(false) function enviar() { if (!email.value.includes('@')) { errorMsg.value = 'Email inválido'; return } if (mensaje.value.length < 10) { errorMsg.value = 'Mensaje muy corto'; return } enviando.value = true errorMsg.value = '' emit('enviar', { email: email.value, mensaje: mensaje.value }) setTimeout(() => { enviando.value = false }, 1500) } </script>
